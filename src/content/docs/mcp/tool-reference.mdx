# MCP Tool Reference

The NoBadFonts MCP Server exposes the following standard tools to AI agents:

---

## `search_fonts`

Searches the font repository by semantic query, classification, and stylistic attributes.

### Arguments

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `query` | `string` | No | Free-form semantic search term (e.g. "brutalist display", "clean editorial") |
| `classification` | `string` | No | `sans`, `serif`, `mono`, `display` |
| `min_weights` | `number` | No | Minimum count of available weights (e.g. 4) |
| `limit` | `number` | No | Maximum items to return (default: 5, max: 20) |

---

## `get_font_details`

Fetches in-depth metadata, license verification, foundry source, and CSS integration code for a specific typeface.

### Arguments

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `font_slug` | `string` | Yes | Unique identifier slug of the typeface |

### Response Schema

```json
{
  "name": "Satoshi",
  "designer": "Indian Type Foundry",
  "license": "SIL Open Font License 1.1",
  "weights": [300, 400, 500, 700, 900],
  "classification": "sans",
  "variable": true,
  "css_url": "https://api.nobadfonts.in/css2?family=Satoshi:wght@300..900"
}
```

## `recommend_pairings`

Recommends harmonious typography pairings tailored to a target design aesthetic.

### Arguments

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `primary_font` | `string` | Yes | Name or slug of the primary headline font |
| `aesthetic` | `string` | No | Mood target (e.g. `minimalist`, `editorial`, `high-tech`, `playful`) |

---

## `upload_font_json`

Creates a new typeface entry in NoBadFonts from a canonical font JSON definition, and enqueues automated binary extraction from GitHub release zip archives.

### Arguments

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `json` | `object` | Yes | Canonical font JSON payload matching the `github-font-output.json` template, including `identity.name` and the `release_zips` array. |
| `skip_existing` | `boolean` | No | If `true` (default), skips creation gracefully if font already exists in catalog. |
| `publish_immediately` | `boolean` | No | If `true` (default), marks font as published immediately; if `false`, creates as draft. |
| `uploader_user_id` | `string` | No | Optional user UUID to assign ownership to (defaults to system admin). |
| `rationale` | `string` | No | Audit note describing font source or provenance. |

---

## `upload_multiple_fonts_json`

Batch creates multiple fonts in NoBadFonts from generated JSONs and queues automated GitHub release downloads (up to 50 fonts per call). Ideal for discovery pipelines.

### Arguments

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `fonts` | `array` | Yes | Array of font creation objects (`{ json, publish_immediately?, rationale? }`). |
| `skip_existing` | `boolean` | No | If `true` (default), skips fonts already in the catalog without failing remaining items. |
| `stop_on_error` | `boolean` | No | If `true`, stops processing on first error; if `false` (default), continues processing remaining fonts. |

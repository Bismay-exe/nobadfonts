# Curation Standards & Submissions

NoBadFonts is a curated community platform. Anyone can propose a typeface, but each submission undergoes review against our typographic quality rubric before going live.

---

## The Submission Rubric

To maintain high standards, submitted fonts must meet the following baseline criteria:

### 1. Optical Integrity
* No overlapping or inverted Bézier curve anchor points.
* Uniform optical stem widths across repetitive letterforms (e.g. `n`, `m`, `h`, `u`).
* Consistent stroke terminations and optical corrections at acute joints (`v`, `w`, `y`).

### 2. File Format & Performance
* Clean, unbloated file sizes (ideally under 35kb per `.woff2` weight after sub-setting).
* Proper metadata tables (`name`, `OS/2`, `post`, `head`) with valid designer attribution.

### 3. Submission Checklist
Before submitting a font on the [Upload Page](/upload):
* [ ] Verify the license is SIL Open Font License, Apache 2.0, or CC0.
* [ ] Confirm at least 2 distinct optical weights are available.
* [ ] Ensure original author / foundry source links are accurate.
* [ ] Include high-resolution preview specimens highlighting character strengths.

# Font Licensing Demystified

Font licenses can feel intentionally complicated. Many proprietary foundries charge separately for desktop usage, monthly web pageviews, mobile app embedding, and PDF distribution.

**NoBadFonts was created to eliminate this headache.**

---

## The Primary License: SIL Open Font License (OFL 1.1)

The vast majority of fonts on NoBadFonts are distributed under the **SIL Open Font License 1.1**, the gold standard of open-source typography.

### What You Can Do
* Use the font in **unlimited commercial projects** (client websites, SaaS products, advertisements).
* Embed the font in **web applications, iOS/Android mobile apps, and games**.
* Print physical goods, books, apparel, and packaging without view limits.
* Bundle and distribute the font files with your open-source software.

### What You Cannot Do
* **Sell the font files by themselves:** You cannot take an OFL font and sell the `.ttf` or `.woff2` file directly for money.
* **Use Reserved Font Names:** If you modify the font outlines, you cannot release the fork under the original author's Reserved Font Name without permission.

<Callout type="success" title="Client Peace of Mind">
Any font tagged with OFL on NoBadFonts can be safely deployed for client work without unexpected licensing audits or monthly pageview invoices.
</Callout>

## Web vs. Desktop Formats

* **`.woff2` (Web Open Font Format 2):** Ultra-compressed Brotli format engineered for browsers. 30–50% smaller than older formats. Always use `.woff2` for websites.
* **`.otf` / `.ttf`:** Desktop outlines meant for local OS installation in Figma, Sketch, Photoshop, or Word.

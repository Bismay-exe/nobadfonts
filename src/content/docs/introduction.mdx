# Welcome to NoBadFonts

**NoBadFonts** is a next-generation, curated typography platform built for designers and developers who demand quality, context, and performance.

The web has a typography problem. You open traditional font catalogs, scroll past 1,400+ unvetted options, type *"Hello World"* in a miniature box, and struggle to make decisions that define an entire brand identity.

NoBadFonts fixes this through **strict human curation**, realistic in-context typography previews, instant CLI tools, and agentic AI integrations.

## Core Capabilities

### 1. Human-Curated Catalog
Every typeface on NoBadFonts passes strict criteria: complete glyph sets, balanced kerning pairs, multiple usable weights, and explicit commercial licensing clarity. No junk fonts, broken diacritics, or licensing traps.

### 2. Live In-Context Testing
Preview typefaces in real UI components — article layouts, landing page hero sections, badges, and dashboard headers — instead of isolated text snippets.

### 3. CLI Companion (`nobadfonts`)
A developer-first command-line utility to search fonts, download optimized `.woff2` files, and automatically inject `@font-face` rules or Tailwind CSS variables into your project.

```bash
# Search and preview fonts directly in your terminal
nobadfonts search "modern sans" --preview
```

### 4. Agentic AI & MCP Server
Connect AI coding assistants directly to NoBadFonts. Your AI editor can automatically recommend pairings, check licensing constraints, and download web fonts while coding.
